The Universal Approximation Theorem is usually taught as reassurance. A neural network with a single hidden layer can approximate any continuous function to arbitrary accuracy — so whatever relationship exists in your data, there is in principle a network that captures it. Nothing is out of reach.

Read it again and it stops being reassuring.

If a network can approximate *any* function, then it can approximate the function that maps your training images to a set of labels somebody generated by rolling dice. That function has no structure. There is nothing in it to learn. And the theorem says a network can fit it anyway.

That's not a loophole in the theorem. It's the theorem working exactly as stated. And it means the thing we usually treat as evidence of learning — the loss going to zero — is evidence of almost nothing.

## What the theorem actually promises

Two caveats travel with the Universal Approximation Theorem, and both are part of the result rather than objections to it.

**It says nothing about generalisation.** The theorem is about representing a function on the data you have. Whether the network does anything sensible on data it hasn't seen is a completely separate question that the theorem does not address, in either direction.

**The network might need to be absurdly large.** "A single hidden layer suffices" is true and says nothing about width. The layer required could be wider than anything you could build or train.

So the honest summary is narrower than the usual one: **a neural network is a function approximator.** Not a reasoner, not a concept-learner. A very flexible curve-fitter, and the theorem is a statement about how flexible.

The natural response is that this is theoretical — that in practice, on real data, a network can't just memorise, because there's too much data and not enough capacity, and the pressure to compress forces it to find real structure.

That's a testable claim, and somebody tested it.

## The experiment

Take a standard image dataset and a standard network that trains to good test accuracy. Now start corrupting the labels: for a growing fraction of the training set, throw away the true label and replace it with a roll of a *k*-sided die, where *k* is the number of classes. Train to convergence at each level of corruption.

Test accuracy behaves exactly as you'd expect. As more labels become noise, the network learns less that transfers, and performance on held-out data slides down toward chance.

**Training accuracy stays at 100%.** At every level. Including the one where every single label is random.

There is no pattern connecting those images to those labels — the labels were generated by a die. The network fits them perfectly regardless. It has enough capacity to memorise the entire training set as a lookup table, and when there's nothing else available, that's exactly what it does.

The conclusion in my notes is the blunt one, and it's right: neural nets are really good function approximators.

But sit with what it implies. **A model reaching perfect training accuracy tells you nothing whatsoever about whether it learned anything.** That's not a warning about overfitting in the usual sense — it's stronger. The two situations, "learned the real structure" and "memorised noise", produce an *identical* training loss curve. You cannot distinguish them from the thing you're optimising. Only held-out data can tell you which one happened, which is why the discipline around validation sets is not bureaucracy.

## The function it found is not the function you wanted

So suppose the network does generalise. Test accuracy is high. Has it learned the concept?

Take a correctly classified image and adjust the *input* to make the loss go up:

$$x \leftarrow x + \eta \frac{\partial J(W, x, y)}{\partial x}$$

Which is training, run backwards and pointed at the wrong thing. Training computes the gradient of the loss with respect to the weights and steps downhill. This computes the gradient with respect to the **input** and steps uphill. Same machinery, same backward pass — a different variable held fixed.

The result is an image that looks unchanged to you and is confidently misclassified.

That's hard to reconcile with "it learned what a panda is". Whatever decision boundary the network drew, it passes close enough to real examples that an imperceptible nudge crosses it. The boundary separates the training data correctly and is shaped nothing like the one you had in mind.

And notice that adversarial examples aren't a bug to be patched. They're a direct consequence of the first two facts. A very flexible function fitted to a finite sample will be constrained where the data is and arbitrary everywhere else — and "everywhere else" starts immediately next to every data point.

## So why does any of it work

Three facts that fit badly together: it can fit anything, it will memorise noise, and the function it settles on is fragile. And yet these models do work. Image classifiers really do classify images they've never seen.

The reconciliation isn't in the model. It's in the data.

Consider the space of all possible images at some resolution — every combination of every pixel value. It is unimaginably large, and it is almost entirely noise. Sample it uniformly for the lifetime of the universe and you will never once produce something that looks like a photograph.

Real images occupy a vanishingly thin, highly structured region of that space. There's a name for that region — the **manifold** — and the important property is that it has far fewer effective dimensions than the space containing it. Real data is high-dimensional in representation and low-dimensional in substance.

That's what rescues the situation. The network isn't asked to be correct across the whole space. It only has to be correct on the sheet, and the training data and the test data come from the same sheet. Fit the sheet and you generalise — not because the model discovered a concept, but because the region it needs to be right about is tiny and the samples cover it.

Which also explains the adversarial result precisely. That "imperceptible nudge" pushes the image **off the manifold**, into the vast region of the space that contains no real data and that the network was therefore never constrained on. Out there, its behaviour was never specified by anything. It was always going to be arbitrary. We just don't normally look.

## What I take from this

Nothing here says the models don't work. They demonstrably do, and the manifold argument explains why without any appeal to understanding.

What it does say is that our vocabulary is wrong. "Learns", "understands", "recognises" all suggest the model acquired a concept and applies it. What actually happened is that a very flexible function was fitted to points on a thin sheet, and it interpolates well between points on that sheet, and it does something undefined everywhere else.

That's less romantic and it predicts the failures better. It predicts adversarial examples. It predicts that distribution shift is fatal rather than merely awkward. It predicts that perfect training accuracy is worthless as a signal.

The network was never doing the thing we said it was. It's just that on the manifold, the difference doesn't show.
